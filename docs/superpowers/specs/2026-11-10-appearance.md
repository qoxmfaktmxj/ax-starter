# 업무 화면 테마

사원관리 담당자는 편집하던 행과 조회 조건을 유지한 채 공통 업무 메뉴의 ‘화면 설정’에서 브랜드 색과 명암을 바꾼다. 사원관리와 화면 템플릿의 왼쪽/상단 메뉴가 같은 설정 창을 사용한다.

- 기본값은 코발트/라이트다. 브랜드는 코발트와 ISU, 모드는 라이트와 다크 중 하나를 고른다. 선택 즉시 문서 전체에 반영한다.
- 로그인 전에 같은 모양을 표시할 수 있도록 이 브라우저의 호스트 전용 설정 쿠키에 1년간 보관한다. 계정/고객 설정과 권한에는 연결하지 않는다. 서버는 허용한 네 조합만 최초 HTML에 반영한다. 누락되거나 잘못된 값은 기본값을 사용한다.
- 사원관리, 템플릿, AG Grid, 감사 기록, 입력 오류, 선택/포커스, 포털 대화상자와 로그인 폼에 역할 색을 적용한다. 다크 모드에서는 3D 장면과 정지 이미지에 동일한 밝기 처리를 사용하고 계절별 자산과 조작은 유지한다.

| 인수 기준 | 재현과 판정 |
| --- | --- |
| AC1 기본값과 복원 | 새 브라우저와 손상된 쿠키로 접속하면 코발트/라이트다. 선택 후 새로고침하고 다른 경로에서도 초기 HTML에 선택이 남는다. |
| AC2 독립적인 두 설정 | 업무 메뉴에서 두 선택을 각각 바꿔 네 조합을 확인한다. 표와 버튼에 계산된 색이 반영되고 현재 선택과 편집 상태가 보존된다. |
| AC3 접근성 | 라디오 그룹은 키보드로 선택할 수 있고 Escape로 닫으면 메뉴 버튼에 포커스가 돌아온다. 320px에서 가로 넘침이 없어야 한다. 상태 텍스트와 버튼 텍스트는 각 배경과 4.5:1 이상이어야 한다. |
| AC4 공통 적용 | 감사 기록과 로그인 화면에서 선택한 명암을 확인한다. 모션 감소 시 정지 화면을 계속 사용한다. 저장 불가 시 현재 화면에는 선택을 적용하고 이를 안내한다. |

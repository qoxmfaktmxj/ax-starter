# ISU 수면 로그인 적용 기준

## 확정한 방향

2026-09-26 사용자가 움직이는 수면 미리보기를 실제 로그인 화면에 적용하도록 요청했다. 이 문서의 수면, 분위기, 슬로건 결정은 기존 눈 지형과 슬로건 판에 대한 이전 계획보다 우선한다.

- 기존 Blender ISU 모델의 둥근 블록, S의 사선 단, 파랑과 초록 큐브를 유지한다. 가까운 벽이나 언덕은 두지 않는다.
- 진입 시 04, 05, 06, 08, 09, 10 중 하나를 무작위로 선택한다.
- 이후 10 화이트, 06 청록, 05 따뜻한 빛, 04 라벤더, 09 비, 08 흑요석 순서로 반복한다. 흑요석에서 화이트로 돌아갈 때 라벤더 새벽빛을 연결점으로 사용한다.
- 유지 45초와 전환 15초를 사용한다. 하늘, 조명, 물, 안개와 비를 같은 시간축에서 부드럽게 보간한다.
- 포인터에 반응하는 수면과 ISU를 유지한다. 블록 뒤에 고정된 얇은 흰 판을 두는 미리보기 방식은 제거한다.
- Challenge the Future와 Share the Future는 판 없이 수면 위에 떠 있는 글자로 표현한다. 터치한 주변 글자가 물결처럼 잠시 흩어졌다 원래 위치로 돌아온다. 수면에 글자의 반사가 보인다.
- Challenge는 로고 초록, Share는 로고 파랑이다. Share의 기본 세기는 0.35, 로그인 성공 시 1이다. 밝은 분위기에서도 글자 외곽과 대비를 확보한다.

## 구현 경계

기존 미완성 `isu-scene.ts`, `isu-blocks.ts`, `isu-glow.ts`, `login-motion.ts` 수정은 보존하고 새 수면 모듈을 연결한다. 인증 요청, 권한, Service, Grid와 다른 작업 파일은 변경하지 않는다. 시안의 재생 조절 버튼은 실제 로그인 화면에 넣지 않는다. 외부 CDN이나 새 외부 서비스는 연결하지 않는다.

입력 중에는 과한 움직임과 새로운 분위기 전환을 억제한다. 페이지가 보이지 않을 때는 재생을 멈추고, 재개 시 시간이 갑자기 건너뛰지 않는다. 초기 로딩, WebGL 실패, 모션 감소에서도 로그인과 읽을 수 있는 정지 슬로건을 제공한다.

## 성공 기준과 검증

1. 실제 로그인 화면에서 선택한 분위기, 수면 반사, 포인터 물결과 ISU 반응이 보인다. 흰 선이나 큰 발광판이 나타나지 않는다.
2. 슬로건을 건드리면 글자가 반응하고 복귀한다. 같은 동작을 반복해도 위치가 누적해서 틀어지지 않는다. 사각 배경 판이 없다.
3. 데스크톱, 세로가 긴 창과 모바일에서 ISU, 슬로건과 로그인 폼이 잘리거나 겹치지 않는다.
4. 순환 경계와 슬로건 복귀 로직을 단위 검사한다. 실제 브라우저에서 초기 로딩 중 로그인, 오류 및 모션 감소 대체 화면, 입력 중 calm, 로그인 성공 Share 변화, 포인터 반응과 가독성을 확인한다.
5. 정적 검사, 단위 검사, DB 통합 검사, e2e와 빌드를 실행한다. 실제 GPU 성능은 별도로 측정한 경우에만 합격을 주장한다.
6. 실행한 명령과 결과를 `docs/PROGRESS.md`에 기록한다. 일회성 Docker 프로젝트는 `ax-water-20260926`으로 격리하고 확인 후 전용 자원을 정리한다.

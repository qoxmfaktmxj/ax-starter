# ISU 수면 로그인 적용 기준

## 확정한 방향

2026-09-26 사용자가 움직이는 수면 미리보기를 실제 로그인 화면에 적용하도록 요청했다. 2026-09-27에는 슬로건을 3D 객체에서 로그인 카드 위의 일반 텍스트로 바꾸기로 결정했다. 이 문서의 수면, 분위기, 슬로건 결정은 기존 눈 지형과 슬로건 판에 대한 이전 계획보다 우선한다.

- 기존 Blender ISU 모델의 둥근 블록, 파랑과 초록 큐브를 유지한다. S의 위아래를 잇는 사선 단은 세 블록으로 만든다. 가까운 벽이나 언덕은 두지 않는다.
- 파란 블록은 매끄러운 푸른 틴팅 유리로 만든다. 빛이 통과하는 모서리와 깊이가 있는 중심을 표현하되 전체가 빈 무색 유리처럼 보이지 않게 한다. 초록 큐브의 CI 색과 ISU 윤곽을 유지한다.
- 진입 시 04, 05, 06, 08, 09, 10 중 하나를 무작위로 선택한다.
- 이후 06 청록 일출, 10 푸른 낮, 05 따뜻한 노을, 04 라벤더 잔광, 09 비 오는 저녁, 08 흑요석 밤 순서로 반복한다. 흑요석에서 청록 일출로 직접 이어진다.
- 유지 15초와 전환 5초를 사용한다. 하늘, 조명, 물, 안개와 비를 같은 시간축에서 부드럽게 보간한다.
- 포인터에 반응하는 수면과 ISU를 유지한다. 수면의 동심원 고리 대신 포인터 이동 방향을 따라 작게 퍼지는 반사 왜곡을 사용하고 분위기별 기본 물결의 세기도 줄인다. 수면에 비친 밝은 면은 흐름에 따라 조금씩 휘고 과하게 하얗게 뭉치지 않게 한다. 블록 위 포인터와 터치에는 가까운 곳의 빛이 잠시 강해지고 떠나면 복귀한다. 블록 뒤에 고정된 얇은 흰 판을 두는 미리보기 방식은 제거한다.
- 06 청록에서 해가 수평선 아래에서 떠오르고, 10 화이트에서 높아졌다가, 05 노을에서 수면 아래로 내려간다. 해의 위치와 빛의 색에 따라 ISU 블록의 조명과 수면 위에 잘게 끊어진 빛길이 함께 달라진다. 04 라벤더에서 잔광이 사라지고 09 비와 08 밤으로 어두워진다. 멀리 있는 수평선에는 얇은 밝기와 안개 층을 둔다. 참고 이미지에 나온 숲, 배, 워터마크, 문구와 가짜 로그인 폼은 넣지 않는다.
- Challenge the Future와 Share the Future는 로그인 카드 바깥 위쪽에 일반 HTML 텍스트로 표시한다. 카드와 같은 왼쪽 선에 맞추고 24~32px 간격을 둔다. 모바일에서도 같은 순서를 유지한다.
- 슬로건 글자는 움직이지 않는다. 마우스를 올린 위치의 글자 안쪽에만 국소 광택을 보이고, 터치와 모션 감소 상태에서는 장식 효과 없이 문구를 읽을 수 있게 한다. 3D 글자, 수면에 비친 글자, 사각 배경 판, 글자 바깥 발광과 두꺼운 외곽선은 사용하지 않는다.
- Challenge는 공식 ISU Green `#99CA3C`, Share는 공식 ISU Blue `#008FD4`를 처음부터 완전한 불투명도로 표시한다. 분위기 전환과 로그인 성공에 맞춰 글자색이나 Share의 불투명도를 바꾸지 않는다. 얇은 글자 그림자로 가독성을 보조하고, 마우스 호버 시 각 글자색보다 밝은 같은 계열의 광택을 글자 안쪽에만 표시한다. 텍스트와 효과는 WebGL에 의존하지 않는다.
- 블록 재질의 기준색도 공식 파랑과 초록을 사용한다. 투과와 장면 조명 때문에 렌더링 픽셀은 평면 CI 견본과 다를 수 있다. Blender MCP 재질 시안에서 선택한 푸른 유리의 투과와 코팅을 GLB에 보존하고, WebGL에서는 내부 흡수와 절제한 스튜디오 반사를 추가한다. Blender의 SSS는 glTF로 전달되지 않으므로 브라우저에서 동일한 산란을 주장하지 않는다. 버튼은 흰 글자 대비를 위해 공식 파랑을 어둡게 혼합한다. 로그인 패널은 공식 Light Gray `#E5E4E0`를 반투명하게, 테두리는 공식 Silver `#A7A9AC`를 연하게 쓴다. Gold `#B4985A`는 팔레트에 보존한다.
- 모바일의 고정된 어두운 영역과 WebGL 대체 화면에서도 두 문구의 색을 그대로 유지한다.

## 구현 경계

기존 미완성 `isu-scene.ts`, `isu-blocks.ts`, `isu-glow.ts`, `login-motion.ts` 수정은 보존하고 새 수면 모듈을 연결한다. 인증 요청, 권한, Service, Grid와 다른 작업 파일은 변경하지 않는다. 시안의 재생 조절 버튼은 실제 로그인 화면에 넣지 않는다. 외부 CDN이나 새 외부 서비스는 연결하지 않는다.

입력 중에는 과한 움직임과 새로운 분위기 전환을 억제한다. 페이지가 보이지 않을 때는 재생을 멈추고, 재개 시 시간이 갑자기 건너뛰지 않는다. 초기 로딩, WebGL 실패, 모션 감소에서도 로그인과 읽을 수 있는 정지 슬로건을 제공한다.

## 성공 기준과 검증

1. 실제 로그인 화면에서 선택한 분위기, 수면 반사, 포인터 물결과 ISU 반응이 보인다. 흰 선이나 큰 발광판이 나타나지 않는다.
2. 포인터를 따라 수면 반사가 흐르되 동심원 고리가 나타나지 않는다. 슬로건은 움직이지 않고 호버한 부분의 글자 안쪽에만 광택이 보였다 사라진다. 사각 배경 판이 없다.
3. 데스크톱, 세로가 긴 창과 모바일에서 세 조각 S의 윤곽과 파란 블록의 질감, 슬로건 및 로그인 폼이 잘리거나 겹치지 않는다. 정지 대체 이미지도 같은 블록 배치를 사용한다.
4. 순환 경계를 단위 검사한다. 실제 브라우저에서 노을 분위기와 초기 로딩 중 로그인, 오류 및 모션 감소 대체 화면, 입력 중 calm, 로그인 성공 전후의 고정 슬로건 색, 포인터 반응 및 터치 가독성을 확인한다. 모션 감소 상태에서는 텍스트 광택을 끈다.
5. 정적 검사, 단위 검사, DB 통합 검사, e2e와 빌드를 실행한다. 실제 GPU 성능은 별도로 측정한 경우에만 합격을 주장한다.
6. 실행한 명령과 결과를 `docs/PROGRESS.md`에 기록한다. 일회성 Docker 검사는 작업마다 고유한 프로젝트 이름으로 격리하고 확인 후 전용 자원을 정리한다.
